# DevTinder

- Create React + Vite project
- Remove unanted code
- Install Tailwind CSS
- Install Daisy UI
- Add Navbar to App.jsx
- Create a seperate Component for Navbar
- Install React Router
- Create BrowserRouter > Routes > Route =/ Body > RouteChildren
- Create an Outlet in Body Component
- Create Footer
- Install axios
- Install CORS in backend with config origin and redentials and on frontend withCredetials config
- Install Redux Toolkit
- Install React redux and configure store, add provider and create slice
